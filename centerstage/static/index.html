分析说明

当前版本用可见人脸判断同一时刻有几位视觉 C 位。时间轴上一种成员颜色对应一个姓名，播放画面上的名字就是这个颜色的人；没有名条的 C 位用浅色标出，不另编姓名。同一时刻两个人会分成上下两色。画面上的成员名条如果只写出一个人，并且这个人正是当时唯一的视觉 C 位，这个名字会留在该轨迹上，直到下一条不同的名条出现。

姓名来源与人物对应关系分开保存。已核实名单不等于识别了画面中的每个人；字幕也可能标注画外演唱者。姓名绑定需要明确证据或你的确认。

遮挡、交叉与切镜可能中断轨迹。不同轨迹确认成同一姓名后，时长会合并；未确认片段不会算到任何人的名下。

后台提前分析，网页按视频时间显示标注。处理跟不上时暂停等待，也可切换完整分析后观看。首次安装和模型准备需要额外时间。
