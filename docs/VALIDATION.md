## 准确性尚未过关

- NEON 有 131.5 s（约 58.8%）没有判定 C 位，剩余区间也没有经过逐帧人工真值验证，不能解释为 41.2% 准确率。
- 产生 682 条轨迹片段，不是 682 个人。遮挡、切镜、灯光和追踪中断造成碎片，尚未实现跨镜头身份连续性。画面差异切镜规则可能把闪光当切镜。
- 9 人候选名单已保存公开来源。视频人物绑定姓名为 0；全自动对应具体人名尚未实现。用户确认后才在框、当前 C 位和姓名时长表中使用名字。
- 快速 OCR 只获得 3 个短字幕区间：89 s 的 AIJING、100 s 的 YOUNG、215 s 的 AIJING。字幕可能指画外演唱者，因此没有据此绑定人物身份。没识别到的字幕保持空白。

## 保留的失败与改进证据

早期 CPU / 动态 batch 的 CoreML 版本处理速度跌到 1× 以下并缓冲暂停，已取消对应测试；不能只看提供器名称便认定有硬件加速。固定 batch=1 和 ALL 计算单元后改善。单帧 CPU 与 CoreML 的 2 个检测结果相比，框坐标最大差约 0.000183 像素、置信度最大差约 5.96e-8，仅说明该帧提供器输出接近，不证明算法准确。

NEON 早期 15 fps、无 OCR 版本约 215.67 s 完成，未明确 C 位约 146.97 s。规则调整后未判定区间减少，但样本率与环境也变了，不能据此报告准确率提升。Apple Vision accurate 模式冷启动曾等待约 152 s，已改为独立线程 fast 模式，代价是字幕覆盖很低。
